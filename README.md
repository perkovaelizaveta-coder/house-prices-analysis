# House Prices — аналіз та візуалізація датасету

Повний цикл роботи з табличним датасетом **House Prices** (Kaggle): від первинного огляду й очищення даних і 12 візуалізацій до першої моделі регресії, що прогнозує ціну житла, з чесною оцінкою якості.

**Автор:** Єлизавета Перькова, НаУКМА, Прикладна математика
**Стек:** Python, Pandas, NumPy, Matplotlib, Seaborn, scikit-learn, Jupyter

## Дані

[House Prices: Advanced Regression Techniques](https://www.kaggle.com/c/house-prices-advanced-regression-techniques/data) — 1460 продажів будинків у м. Еймс (Айова), 81 ознака. Цільова змінна — `SalePrice`.

Файл даних у репозиторій не включено. Завантаж `train.csv` з Kaggle, перейменуй на `house_prices.csv` і поклади поруч із ноутбуками.

**Очищення та підготовка**
- видалено колонки з понад 80% пропусків (`PoolQC`, `MiscFeature`, `Alley`, `Fence`);

- створено ознаки `HouseAge`, `TotalSF`, `RemodAge`.

**Візуалізації:** гістограма, scatter, bar, hbar, boxplot, violin, pie, KDE, heatmap, line, stacked bar.

## Моделювання (baseline)

Дані ділю на train/test (80/20), попередня обробка й модель зібрані в одному `Pipeline`, щоб уникнути витоку інформації з тесту.

| Модель | RMSE, $ | R² |
|---|---|---|
| Середня ціна (baseline) | 74 324 | 0.00 |
| Лінійна регресія | 26 228 | 0.875 |
| Лінійна регресія, log(ціни) | 21 668 | 0.915 |
| Ridge, log(ціни), alpha=10 | 19 865 | 0.929 |

- Крос-валідація показала нестабільність лінійної регресії через два викиди (дуже великі будинки з низькою ціною, які видно на візуалізації); після їх видалення результат стабільний.
- `alpha` для Ridge обрано крос-валідацією лише на тренувальних даних.
- Обмеження: один розподіл train/test, лише лінійні моделі, невеликий витік через медіану `LotFrontage`, яка рахується до розбиття (описано в ноутбуці).

## Ключові висновки (аналіз даних)

- Розподіл ціни скошений вправо: більшість будинків коштує $100K–$250K.
- Найсильніше з ціною пов'язані якість будівництва (`OverallQual`), загальна площа (`TotalSF`) і житлова площа; район також суттєво впливає.
- Кількість спалень не має прямолінійного зв'язку з ціною, а `OverallCond` майже не корелює з нею, на відміну від `OverallQual`.
- `TotalSF` і житлова площа сильно взаємопов'язані, тому для майбутнього моделювання потрібно враховувати мультиколінеарність.
